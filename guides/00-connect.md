# 0. 연결 점검 (처음 한 번)

목표: 이후 단계가 매끄럽도록 쓸 수 있는 연결을 처음에 한 번에 해 둔다. 이미 연결된 것은 묻지 않는다. 거절한 것은 기억하고 다시 묻지 않는다.

## 1) 지금 쓸 수 있는 도구 확인 (말하지 않고 확인만)

네게 연결된 커넥터·MCP·앱 연결 중 아래가 있는지 본다.

| 연결 | 쓰는 곳 |
|---|---|
| 구글 문서·드라이브 | 4단계 자소서·3단계 분석을 사용자 드라이브에 구글 문서로 만든다 |
| 구글 캘린더 | 고른 공고의 마감일·면접 일정을 등록한다(등록할 때마다 먼저 묻는다) |
| 지메일(또는 쓰는 메일) | 사람인·잡코리아 등이 보낸 추천 공고 메일, 면접·서류 결과 메일을 읽어 정리한다 |
| 채용 사이트 로그인 (사람인·잡코리아·리멤버 등) | 등록해 둔 이력서를 불러와 1단계 프로필을 채운다. 스크랩·지원 현황을 본다 |
| 깃헙 (선택) | 빠진 사이트·오류를 사용자 대신 스킬 저장소에 제보한다 (`guides/feedback.md`) |

## 2) 사용자에게 한 번에 묻기 (짧게)

없는 것만 골라 한 메시지로 묻는다. 구글은 추천, 나머지는 모두 선택이다. 이 단계는 질문 1번으로 끝낸다.

예:
"시작 전에 연결 몇 가지만 확인할게요. 다 선택이고, 나중에 해도 돼요.
- 추천: 구글 계정 — 자소서를 내 구글 드라이브에 문서로 바로 만들어 드려요.
- 있으면 편해요: 구글 캘린더(마감일 등록), 메일(추천 공고·면접 메일 정리), 사람인·잡코리아 로그인(내 이력서 불러오기).
- 선택: 깃헙 — 빠진 사이트나 오류를 제가 대신 개발자에게 알려 드릴 수 있어요. 이력서 같은 개인정보는 보내지 않고, 올리기 전에 꼭 보여 드려요.
연결할 것만 말씀해 주세요."

## 3) 연결 안내

- 사용자가 고른 것만, 네 앱의 실제 화면 기준으로 단계별로 짧게 안내한다.
  - 피클: 앱 연결에서 Google 계정 연결(또는 채팅에서 연결 요청 → 연결 카드 승인). 사이트 로그인은 로그인 카드로 금고에 저장.
  - Claude: 설정 → 커넥터에서 Google Drive·Gmail·Google Calendar·GitHub.
  - ChatGPT: 설정 → 앱에서 Google Drive·Gmail·Google Calendar·GitHub.
  - 메뉴 이름이 다르면 네 앱 기준으로 고쳐 말한다.
- 비밀번호를 채팅으로 받지 않는다. 네 앱의 로그인·금고 기능으로만 연결한다.
- 연결이 끝나면 무엇이 됐는지 한 줄로 알리고 1단계로 넘어간다. 예: "구글 문서·캘린더 연결됐어요. 이제 원하시는 일부터 여쭤볼게요."

## 4) 기억할 것

연결된 것, 거절한 것을 기억에 남긴다. 다음 대화에서는 이 단계를 건너뛴다.
