# 1. 프로필 정리

목표: 공고 추천과 자소서에 쓸 사용자 정보를 한 번 정리해서 기억에 저장한다. 다음부터는 다시 묻지 않는다.

## 진행

1. 가진 자료부터 받는다. 한 메시지로 묻는다:
   "예전에 써 둔 이력서·경력기술서·자기소개서가 있으면 주세요(파일, 링크, 붙여넣기 다 돼요). 자소서는 회사가 달라도 괜찮아요. 거기서 경험과 말투를 뽑아 두면 새 자소서가 내 글처럼 나와요."
   - 채용 사이트 로그인이 연결돼 있으면 등록된 이력서·자소서를 불러온다.
   - 구글 드라이브가 연결돼 있으면 "드라이브에서 '자기소개서', '이력서' 문서를 찾아볼까요?"라고 묻고, 허락하면 찾아 목록을 보여 준 뒤 고른 것만 읽는다.
   - 자료가 있으면 그걸로 채우고 빈 칸만 묻는다.
2. 없으면 아래를 **한 번에 하나씩, 짧게** 묻는다. 모르면 넘어가도 된다고 말한다.
   - 지금 상태: 취준(신입) / 재직 중 이직 / 쉬는 중
   - 원하는 직무(여러 개 가능)와 산업
   - 경력: 회사·기간·맡은 일 (신입이면 전공·인턴·프로젝트·대외활동)
   - 성과: 숫자로 말할 수 있는 것 (매출, 비용 절감, 처리 건수, 수상 등)
   - 자격증·어학·툴
   - 희망 지역, 연봉 하한, 고용형태(정규직 등)
3. 예전 자소서가 있으면 아래 두 가지를 뽑는다(원문 전체는 저장하지 않고 요약만).
   - **경험 소재**: 에피소드마다 한 줄(상황·내 역할·행동·결과 숫자). 같은 경험이 여러 자소서에 나오면 하나로 합친다.
   - **글 스타일**: 말투(~했습니다/~했어요), 문장 길이(짧게/길게), 자주 쓰는 표현·첫 문장 습관, 사용자가 싫어할 만한 표현(있으면).
4. 아래 형식으로 정리해 보여 주고 "맞나요?" 한 번만 확인한 뒤 기억에 저장한다.

```markdown
## 프로필
- 상태: 재직 중 이직 (마케터 3년 차)
- 희망: 퍼포먼스 마케팅 / 이커머스·뷰티 / 서울·판교 / 4,000만원 이상 / 정규직
- 경력:
  - A사 (2023.03~현재) 퍼포먼스 마케터 — 메타·구글 광고 운영, 월 광고비 5천만원 관리
- 성과: ROAS 180% → 260% (6개월), 신규 가입 전환율 1.2%p 개선
- 기술·자격: GA4, 구글애즈 인증, SQL 기초
- 강점 한 줄: 데이터로 광고 효율을 끌어올리는 사람

## 경험 소재 (예전 자소서·이력서에서)
- [광고 효율 개선] 신규 브랜드 광고 담당 → 타깃·소재 A/B 테스트 주도 → ROAS 180%→260% (6개월)
- [협업] 디자인팀과 소재 제작 주기 단축 → 주 1회 → 주 3회 테스트

## 글 스타일
- 말투: ~했습니다 (격식체), 문장 짧게
- 습관: 첫 문장에 결과 숫자, "데이터로" 자주 씀
- 피할 것: "열정", "최선을 다하겠습니다"

## 직군과 검색할 사이트 (2단계에서 정함)
- 직군: 05 마케팅·광고·홍보·MD (파일 `guides/jobs/05-마케팅MD.md`)
- 스크립트: saramin, jobkorea, wanted, remember
- 브라우저: 광고정보센터

## 내 요청사항 (결과 내기 전에 항상 확인)
- 공고: 스타트업 빼고, 판교·분당만, 연봉 4,000만원 이상
- 자소서: 말투 덜 딱딱하게, 항목당 500자 이내, 첫 문장에 성과 숫자
- 알림: 아침 8시, 새 공고 5개까지
```

## 규칙

- 사용자가 말하지 않은 경험·숫자는 채우지 않는다. 빈 칸은 비워 둔다.
- 주민등록번호·주소·연락처·가족사항 같은 민감 정보는 자료에 있어도 프로필에 옮기지 않는다.
- 자료는 나중에 더 받아도 된다. "예전 자소서 더 줄게"라고 하면 경험 소재·글 스타일에 더하고 겹치는 건 합친다.
- 사용자가 나중에 "프로필 바꿔줘"라고 하면 바뀐 부분만 고쳐 다시 저장한다.
- "내 요청사항"은 처음엔 비워 둔다. 사용자가 계속 적용될 요청을 할 때마다 공고·회사 분석·자소서·알림 중 맞는 줄에 짧게 더한다. 반대되는 새 요청이 오면 옛 것을 지우고 바꾼다. "내 요청사항 보여줘"라고 하면 그대로 보여 주고, 지워 달라면 지운다.

## 5. 직군과 검색할 사이트 (프로필 바로 다음, 처음 한 번)

1. `guides/jobs/index.md`를 열어 사용자 직무에 맞는 직군 파일 **하나**를 고르고 연다(세부 직무·검색 키워드·사람인 직무 코드·전문 사이트).
2. 그 직군에서 쓸 사이트를 **추천 5~6곳**으로 추린다: 스크립트 사이트 3~4곳(직군 파일 `스크립트:` 줄 + 아래 기본 조합, 전체 목록은 `python3 career.py sites`) + 브라우저로 열 전문 사이트 1~2곳(직군 파일에서 사용자 세부 직무에 가장 맞는 곳).
3. 사용자에게 짧게 보여 주고 고르게 한다. 예:
   "○○ 직군은 이런 곳에서 공고를 찾아요.
   - 빠르게 찾는 곳(추천): 사람인, 잡코리아, 원티드, 리멤버
   - 직접 열어 보는 전문 사이트(추천): 베이크잡
   - 더 볼 수 있는 곳: 푸드앤잡, 요리사잡, 알바천국 …
   사이트를 많이 볼수록 하루 사용량이 빨리 닳아요. 안 보실 곳은 빼고, 더 보실 곳은 말씀해 주세요. 그냥 '좋아'라고 하시면 추천대로 할게요."
4. 고른 결과를 프로필의 "검색할 사이트"에 저장한다. 다음부터 공고 찾기·매일 알림은 이 목록만 쓰고, 직군도 다시 고르지 않는다.
5. 나중에 "○○도 같이 봐줘", "○○는 빼줘", "검색할 사이트 보여줘"라고 하면 그 목록을 바꾸거나 보여 준다.

기본 조합 (`--sites` 값):
  - 기본: `saramin,jobkorea`
  - IT·기획·디자인·마케팅: `+wanted` / 개발자: `+jumpit`
  - 경력직·헤드헌팅: `+remember`
  - 대기업·공기업 신입 공채: `+jasoseol`
  - 금융·증권·운용: `+kofia` / 리츠·부동산 운용·개발: `+kareit,kofia`
  - 공공기관: `alio` / 공무원 임기제·경력경쟁·공무직: `gojobs` / 해외: `worldjob`

6. 다 정해지면 한 줄로 마무리하고 2단계로 간다: "설정 끝났어요. 바로 맞춤 공고 찾아볼게요."
