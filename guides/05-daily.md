# 5. 매일 새 공고 알림

사용자가 원할 때만 한다.

1. 마지막으로 쓴 검색 조건(키워드·지역·경력 등)을 확인한다. "이 조건으로 매일 아침 8시에 새 공고만 보내 드릴까요?"
2. 네 예약 작업 기능으로 매일 반복 작업을 만든다. 작업 내용:
   - 사이트는 프로필의 "검색할 사이트"만 쓴다(토큰 절약). 알림용으로 더 줄이고 싶으면 사용자에게 물어 스크립트 사이트만 쓴다.
   - 스크립트 모드: `python3 career.py search -k "…" --sites {검색할 사이트} --location … --experience … --title-has "…" --exclude "…" --new-only --max 10` (제목 조건·뺄 말은 프로필 "검색 조건" 그대로)
     (`--new-only`는 이미 보여 준 공고를 뺀다. 기록은 `career_data/seen.json`. 예약 작업에서 파일이 사라지는 환경이면 브라우저 모드처럼 기억에 보여 준 링크를 남긴다.)
   - 브라우저 모드: 02-find-jobs의 주소로 검색하고, 기억해 둔 링크와 겹치는 공고는 뺀다.
3. 메일이 연결돼 있으면 사람인·잡코리아 등이 보낸 추천 공고 메일과 면접·서류 결과 메일도 함께 확인해 한 번에 정리한다.
4. 새 공고가 없으면 "오늘은 새 공고가 없어요" 한 줄만 보낸다. 길게 쓰지 않는다.
5. 하루 사용량을 아끼기 위해 하루 한 번만 실행한다.

## 끄기·바꾸기

- "알림 꺼줘", "알림 멈춰줘" → 네 예약 작업 목록에서 이 알림 작업을 지우고 "알림 껐어요" 한 줄로 알린다.
- "알림 시간 바꿔줘", "주말엔 빼줘", "조건 바꿔줘" → 예약 작업의 시간·요일·검색 조건을 고치고 바뀐 내용을 한 줄로 보여 준다.
- 사용자가 예약 작업을 직접 보고 싶어 하면 네 앱의 예약 작업 화면 위치를 알려 준다(피클은 채팅에서 "예약한 작업 보여줘").
- 바뀐 알림 설정은 프로필 "내 요청사항"의 알림 줄에도 반영한다.
