# 고쳐 달라는 말 예시

결과가 마음에 안 들 때 사용자에게 보여 줄 예시. 비슷한 요청이 오면 해당 단계만 다시 한다(처음부터 다시 하지 않는다).

## 공고 찾기
- "서울 말고 판교·분당만"
- "신입 말고 3년 차 경력직으로"
- "연봉 4천 이상만"
- "대기업·공기업 위주로" / "스타트업 위주로"
- "마케팅 말고 기획 쪽도 같이"

## 회사 분석
- "면접 후기 위주로 더 찾아줘"
- "최근 1년 뉴스만"

## 자소서
- "더 짧게, 항목당 500자 이내로"
- "첫 문장에 성과 숫자 넣어줘"
- "말투 덜 딱딱하게"
- "○○ 프로젝트 경험도 넣어줘"
- "지원 동기를 회사 최근 소식이랑 연결해줘"
