# 4. 자소서 초안 → 내 구글 문서 (안 되면 워드)

입력: 프로필 + 3단계 요건 정리(없으면 공고 본문만 읽고 바로 작성).

## 구성

- 공고에 자소서 항목이 있으면 **그 항목과 글자 수를 그대로** 따른다.
- 없으면:
  - 신입·일반: 1) 성장 과정·자기소개(400~600자) 2) 지원 동기(500~700자) 3) 직무 역량·경험(600~800자, STAR로 경험 2~3개) 4) 입사 후 포부(400~500자, 1~2년·3~5년)
  - 경력직: 1) 지원 동기(300~500자) 2) 경력 기술(500~800자, 프로젝트·성과 중심) 3) 입사 후 기여(300~500자)

## 쓰는 법

- 격식체(~했습니다)로 통일한다. "열심히", "최선을" 같은 빈말과 전 회사 비판은 쓰지 않는다.
- 공고 키워드를 자연스럽게 넣고, 회사의 사업·최근 소식을 한 번은 언급한다.
- **숫자·사례는 프로필에 있는 것만 쓴다.** 없으면 `[직접 입력: 예) 처리 건수 몇 건]`으로 비워 둔다. 경험을 지어내지 않는다.
- 연차·경력 차이를 스스로 깎아내리지 않는다. 가진 기간 안의 밀도와 성과를 앞세운다.
- 프로필에서 경험 유무가 안 보이는 주제는 본문 뒤 "## 바꿔 끼울 문단"에 주제마다 "경험 있음 / 경험 없음" 두 문단(150~300자)을 둔다. 사용자가 실제 상황에 맞는 쪽을 고른다.
- 맨 끝 "## 핵심 메시지"에 한 줄.

## 형식

```markdown
# {회사명} {포지션} 자기소개서 초안

## 1. 지원 동기 (520자)
…

## 2. 경력 기술 (740자)
…

## 바꿔 끼울 문단
### 코드 리뷰 문화 — 경험 있음
…
### 코드 리뷰 문화 — 경험 없음
…

## 핵심 메시지
…
```

## 결과물 주기 (사용자 본인 계정에)

문서 제목: `자소서_{회사명}_{포지션}` (분석은 `분석_{회사명}`)

1. **구글 문서 (1순위)**: 네게 구글 문서·드라이브 도구(커넥터·MCP·연결된 앱)가 있으면 사용자 드라이브에 구글 문서로 만들고 링크를 준다. 사용자가 거기서 바로 고치고 휴대폰으로도 이어 볼 수 있다.
2. **연결 유도**: 구글 문서 도구가 아직 연결 안 됐으면, 문서를 만들기 전에 연결부터 안내한다. 피클은 구글 앱을 연결하면 구글 문서를 만들 수 있다(확인됨).
   - "자소서를 내 구글 드라이브에 문서로 바로 만들어 드릴게요. 그러려면 구글 계정 연결이 한 번 필요해요. 지금 연결해 볼까요? (30초면 돼요. 안 해도 워드 파일로 드려요)"
   - 연결 방법을 네 앱의 실제 화면 기준으로 단계별로 짧게 안내한다. 예: 피클은 앱 연결에서 Google 계정 연결(또는 채팅에서 연결 요청 → 연결 카드 승인) / Claude는 설정 → 커넥터 → Google Drive / ChatGPT는 설정 → 앱 → Google Drive. 메뉴 이름이 다르면 네 앱 기준으로 고쳐 말한다.
   - 연결되면 바로 문서를 만들고 링크를 준다.
   - 사용자가 싫다고 하면 워드로 주고, 다시 권하지 않고 기억해 둔다.
3. **워드 파일**: 구글 문서를 못 쓰면 .docx로 준다. 스크립트 모드면 마크다운을 저장하고 `python3 career.py docx -i 자소서.md`, 아니면 네 문서 만들기 기능.
4. **채팅 본문**: 파일도 못 만들면 본문을 그대로 보낸다.

마지막 안내 (두 줄):
   - "`[직접 입력]` 칸은 실제 숫자로 채워 주세요. AI 초안은 뼈대고, 내 경험이 들어가야 합격 자소서가 돼요."
   - "더 짧게, 첫 문장에 성과 넣기, 말투 부드럽게 같은 수정도 말씀만 하세요."
