# 제보: 개선 요청을 저장소에 등록

이 스킬은 사용자 제보로 좋아진다. 아래 경우 사용자에게 한 줄로 제보를 권한다(같은 대화에서 한 번만).

- "이 사이트도 넣어줘", "○○ 직군은 ○○에서 많이 구해요" 처럼 **빠진 사이트**를 말할 때
- 스크립트 오류, 엉뚱한 공고만 나오는 등 **검색이 이상할 때**
- 직군 분류·키워드·자소서 형식 등 **스킬 자체를 고쳐야 할 때**

권하는 말 예: "이 내용을 스킬 개발자에게 알려 두면 다음부터 모두가 쓸 수 있어요. 제가 대신 등록할까요?"

## 등록할 내용 (개인정보 금지)

공개 글이다. **이름·연락처·이력서·회사명(본인 재직)·프로필 내용은 절대 넣지 않는다.** 아래만 쓴다.

```
제목: [사이트 추가] 베이크잡 — 제과제빵·바리스타
본문:
- 종류: 사이트 추가 / 검색 오류 / 직군·결과 개선
- 직군: 19 음식·조리 (제과·제빵)
- 내용: 빵집·베이커리 카페 구인은 베이크잡에 가장 많다
- 주소: https://bakejob.kr/jobs
- 오류면: 실행한 명령과 오류 메시지 (개인정보 지우고)
- 에이전트: 피클 / Claude / ChatGPT 등
```

**올리기 전에 이 내용을 사용자에게 보여 주고 "올릴까요?"라고 묻는다.** 좋다고 할 때만 등록한다.

## 등록 방법 (되는 것부터)

1. **깃헙 연결(커넥터·MCP)이 있으면**: `Whosekey-Labs/career-skill` 저장소에 이슈를 만들고 링크를 준다.
2. **없으면**: 미리 채운 이슈 링크를 준다. 사용자가 깃헙 로그인 후 "Submit"만 누르면 된다.
   `https://github.com/Whosekey-Labs/career-skill/issues/new?title={제목}&body={본문}` (제목·본문은 URL 인코딩)
3. **깃헙 계정이 없으면**: 오픈채팅방을 안내한다. https://open.kakao.com/o/g3vAeBWi
