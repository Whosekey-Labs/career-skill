# 2. 맞춤 공고 찾기

## 1) 검색 계획 (생각만, 출력하지 않음)

- 프로필의 직군 파일과 "검색할 사이트"를 쓴다. 없으면 `guides/01-profile.md`의 "2) 직군과 검색할 사이트"부터 한다.
- 키워드 2~3개를 정한다. 사람인 직무 코드(`--job-code`)는 **키워드와 함께** 준다(코드만 주면 사람인 하나만 검색된다).
- 조건: 지역, 경력(신입/경력/경력무관), 연봉 하한(만원), 고용형태. 말하지 않은 조건은 넣지 않는다.
- 지역은 시·도(서울·경기·부산 등)나 그 아래 지역(판교·분당·해운대 등)으로 준다. 시·도 아래 지역은 스크립트가 시·도로 검색한 뒤 결과의 지역으로 거른다(career.py 0.8.0부터). 지역이 적히지 않은 공고는 "지역 확인 필요"로 둔다.
- 사이트: "검색할 사이트"의 스크립트 사이트를 `--sites`로 쓴다(키워드 수 × 사이트 수 ≤ 16). 전체 목록은 `python3 career.py sites`.

## 2) 실행

### 스크립트 모드

```bash
python3 career.py search -k "퍼포먼스 마케터,그로스 마케터" --location 서울 --experience 경력 --max 15
python3 career.py search -k "부동산 PF,자산운용" --sites saramin,jobkorea,kofia --experience 경력
python3 career.py search -k "백엔드" --sites saramin,wanted,jumpit,remember --experience 경력
python3 career.py sites                          # 스크립트로 검색할 수 있는 사이트 키 목록
python3 career.py links -k "퍼포먼스 마케터"     # 브라우저로 볼 사이트 링크 (캐치·링커리어 등)
```

- 한 번 실행에 요청은 16번까지다(키워드 수 × 사이트 수 ≤ 16).
- 결과 목록은 **그대로** 보여 준다(아래 3) 공통 규칙의 마감 제외·주의 표시만 더한다). 다시 요약하거나 표로 바꾸지 않는다. 마감일·급여·지역을 고치거나 짐작해서 채우지 않는다. 사이트에 없는 값은 비워 둔다.
- 결과가 3건 미만이면 키워드를 넓히거나(예: "퍼포먼스 마케터" → "마케팅") 조건을 하나 빼고 한 번만 다시 한다.
- 오류가 나면 그 사이트만 브라우저 모드로 한다.

### 브라우저 (기본 흐름에 포함)

- **직군 전문 사이트**: "검색할 사이트"에 들어 있는 브라우저 사이트를 사용자가 시키지 않아도 연다. 검색 결과 1~2페이지에서 공고를 골라 스크립트 결과와 합친다.
- **스크립트가 실패했을 때**: 같은 사이트를 브라우저로 연다.
  - 사람인: `https://www.saramin.co.kr/zf_user/search/recruit?searchword={키워드}` (서울 `&loc_mcd=101000`, 경기 `102000` / 경력 `&exp_cd=2`, 신입 `1` / 직무 코드 `&cat_kewd={코드}`)
  - 잡코리아: `https://www.jobkorea.co.kr/Search/?stext={키워드}&tabType=recruit`
  - 원티드: `https://www.wanted.co.kr/search?query={키워드}&tab=position`
  - 리멤버: `https://career.rememberapp.co.kr/job/postings` → 검색창에 키워드
  - 자소설닷컴: `https://jasoseol.com/search?keyword={키워드}`
- **스크립트가 지원하지 않는 종합 사이트**: 캐치, 링커리어, 로켓펀치 (`python3 career.py links -k 키워드`로 주소 확인)

출력 형식(스크립트와 같게):

```
### 마감 임박 (7일 안)
1. **회사명** 공고 제목
   - 경력 · 연봉 · 지역 · 고용형태 · 마감 11/15
   - 사이트: 링크
### 그 외
...
```


## 3) 공통 규칙 (스크립트·브라우저 결과 모두)

- **마감 지난 공고는 뺀다.** 스크립트가 거르지만 제목·마감 칸에 지난 날짜(예: "(~11/9)")나 '마감'·'모집완료'가 남아 있으면 목록에서 뺀다.
- **사기 의심 표시**: 목록에서는 **제목·조건 칸에 드러난 신호만** 본다(본문 확인은 3단계). 선입금·교육비·장비값, 통장·체크카드 요구, 업무 설명 없는 고수익 재택·부업, 인수금을 내는 지입, 회사명이 없는 공고는 그 항목 끝에 `(주의: 선입금 요구 의심)`처럼 짧게 표시하고, 목록 아래에 "표시된 공고는 지원 전에 회사 정보를 꼭 확인하세요" 한 줄을 붙인다.
- **헤드헌팅 공고**는 회사 이름 칸이 서치펌일 수 있다. 목록에 `(헤드헌팅)`을 붙인다.

## 4) 마무리 안내 (한 줄씩)

- "마음에 드는 공고 번호 1~2개 골라 주시면 회사 분석이랑 자소서까지 해 드릴게요."
- "조건 바꾸고 싶으면 '판교만', '신입으로', '연봉 4천 이상'처럼 말씀해 주세요."
