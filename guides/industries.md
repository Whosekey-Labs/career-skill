# 직군별 검색 키워드·사이트

키워드는 2~4개만 고른다. 직무명 + 흔한 다른 이름을 섞는다. 표에 없는 직군은 같은 방식으로 만든다.

| 직군 | 키워드 예시 | 사이트 (기본 사람인·잡코리아에 더할 것) |
|---|---|---|
| 부동산 금융·개발 | 부동산 PF, 부동산 개발, 신탁, 리츠, 자산운용 AM, PM, 시행 | 금투협, 리멤버 |
| 금융·증권·운용 | 자산운용, 증권 리서치, 리스크관리, IB, 펀드회계, 신탁회계, 컴플라이언스 | 금투협, 리멤버 |
| 은행·보험 | 은행 공채, 여신심사, 보험 계리, 언더라이팅, 손해사정 | 금투협, 자소설닷컴(공채) |
| 개발(IT) | 백엔드, 프론트엔드, 풀스택, 안드로이드, iOS, 데이터 엔지니어, DevOps, QA | 원티드 링크, 리멤버 |
| 데이터·AI | 데이터 분석가, 데이터 사이언티스트, 머신러닝 엔지니어, AI 엔지니어 | 원티드 링크 |

| 생산·제조·품질 | 생산관리, 생산기술, 품질관리(QC/QA), 설비보전, 공정 엔지니어 | 자소설닷컴(대기업) |

## 팁

- 경력직: "경력"을 키워드에 넣지 말고 `--experience 경력` 조건으로 준다.
- 직무가 넓으면 산업을 붙인다: "마케팅" → "뷰티 마케팅", "이커머스 마케팅".
- 결과가 적으면 상위 직무로 넓힌다: "그로스 마케터" → "마케팅".
