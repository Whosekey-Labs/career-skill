## 어디서 찾나

- 스크립트: `saramin,jobkorea,remember` / 공공기관 행정직 `alio` / 공무직·기간제 `gojobs` / 직군 전문 `work24,klaw,lawjob,kabl,kpaa,peoplenjob,linkedin,hibrain`
- 전 직무 공통:
  - 고용24: `https://www.work24.go.kr/wk/a/b/1200/retriveDtlEmpSrchList.do?srcKeyword={키워드}` — 중소기업 사무직·법률사무소 직원. 키워드는 `srcKeyword`(`keyword`만 쓰면 무시됨) (스크립트: `work24`)
- 변호사·사내법무:
  - 대한변협 취업정보센터: `https://www.klaw.or.kr/career/recruit1` — 로펌·사내변호사, 신입~경력. 화면은 JS. 공개 JSON: `POST https://www.klaw.or.kr/career/api/recruit/search` (JSON 본문 `{"pageNo":1,"pageSize":20,"kword":"{키워드}","ktype":"title","s_kind":"recruit","s_recruit_status":["ing","oncont"],"s_with_headhunt":"Y","orderBy":"no","orderDesc":true}`, 헤더 `Mode: front`), 상세 `/career/recruit/{no}` (스크립트: `klaw`)
  - 서울지방변호사회 채용정보: `https://www.seoulbar.or.kr/site/employment/EmploymentAreaRecruit.do` — 변호사·사무직원 채용 (회원 로그인 필요)
- 법률사무소 직원(사무장·송무·회생파산):
  - 법무잡(법률구인구직.com): `https://www.xn--2e0ba292g29chuslhd.com/bbs/board.php?bo_table=guin&sfl=wr_subject&stx={키워드}` — 로펌·법률사무소 사무장·서면실장·회생파산 서류직원·등기 사무원, 어쏘·사내변호사도 섞인다 (2026-11-05 등록 확인) (스크립트: `lawjob`)
- 법무사 사무소:
  - 지방법무사회 구인 (대한법무사협회 안내 `https://kjaar.kabl.kr/mod/page/view.do?MID=kjaa_page_job`): 전국 공통 JSON `http://lawlandr.kabl.kr/modules/kabl/job/list_json.kabl?loc=&page=1` — 등기·송무·회생 사무원, 경력 위주. 키워드 검색 없음(지역 `sch_region`으로 거름) (스크립트: `kabl`)
- 변리사·특허사무소:
  - 대한변리사회 구인정보: `https://www.kpaa.or.kr/kpaa/info/readJobOfferList.do?srch_job_type=4&th0005MngNo=16&srchTtl={키워드}` — 변리사. `srch_job_type=9`는 직원(명세사·특허조사·해외출원 관리·상표 사무). 로그인 없이 목록 보임 (스크립트: `kpaa`)
- 비서·리셉션:
  - 피플앤잡: `https://www.peoplenjob.com/jobs?field=all&q={키워드}` — 외국계 비서·EA·Office Manager, 경력 위주 (예: 비서, Executive Assistant) (스크립트: `peoplenjob`)
  - 링크드인: `https://www.linkedin.com/jobs/search?keywords={키워드}&location=South%20Korea` — 외국계 EA·Legal Counsel (스크립트: `linkedin`)
- 교육·공공 행정:
  - 하이브레인넷 직원 채용: `https://www.hibrain.net/recruitment/categories/JOB/categories/EMP/recruits?sortType=SORTDTM` — 대학·연구기관·공공기관 직원(행정·계약직). 최신순 목록, 키워드는 화면에서 (스크립트: `hibrain`)
  - 경기도교육청 구인구직: `https://www.goe.go.kr/recruit/ad/func/pb/hnfpPbancList.do?mi=10502` — 학교 교무행정실무사·계약직 (경기, 검색은 화면에서)
  - 국가공무원 채용시스템: `https://gongmuwon.gosi.kr/crrut/indexMain.do` — 국가직 경력경쟁·행정
- 행정사·비서협회·속기 단체 구인 게시판은 확인되지 않았다. 고용24·사람인에서 "행정사사무소", "속기사"로 찾는다.
