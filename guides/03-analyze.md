# 3. 회사 분석 + 공고 요건 정리

사용자가 고른 공고 1~2개만 한다. 공고마다 아래 두 가지를 한 번에 만든다.

## 1) 공고 본문 읽기

- 스크립트 모드: `python3 career.py job --url "공고 링크"`
  - 출력에 "## 공고 이미지"가 있으면 그 이미지를 열어 직접 읽는다(상세 요강이 이미지인 공고가 많다). "## 지원 링크"가 있으면 회사 홈페이지 공고도 열어 본다.
- "본문이 짧아요"가 나오거나 스크립트가 열지 못하는 사이트의 공고면 브라우저로 그 공고를 연다. 이미지 공고면 이미지 글자를 읽는다.

## 2) 회사 자료 (웹 검색 3~4번만)

검색어 예: "{회사명} 사업", "{회사명} 2026 뉴스", "{회사명} 실적"(상장사·큰 회사일 때만), "{회사명} 면접 후기"
- 검색 결과에 근거가 있는 것만 쓴다. 회사 이름만 보고 짐작하지 않는다. 없으면 "확인 못 함".

## 3) 출력 형식 (짧게, 이모지 없음)

```markdown
## 회사 분석 — {회사명}
- 한 줄 요약: (지원할 때 가장 강조할 메시지)
- 하는 일: 2~3줄
- 최근 소식: 날짜 · 내용 · 출처 (2~3개)
- 준비하면 좋은 것: 면접·자소서 전에 알아 둘 주제 2~3개
- 확인해 볼 점: 사실 기반, 단념 톤 금지 (예: "조직 개편 중 — 면접에서 팀 구조 질문해 보기")

## 공고 요건 정리 — {포지션}
- 핵심 조건 (원문 그대로): 마감 … / 급여 … / 근무지 … / 고용형태 … — 공고에 없으면 "공고에 없음", 이미지에서 읽었으면 "(이미지에서 읽음)", 끝에 원문 링크와 확인 시각
- 하는 일: …
- 필수: …
- 우대: …
- 자소서 항목: (공고에 있으면 제목·글자 수 그대로)
- 핵심 키워드: 5~8개 (자소서에 자연스럽게 넣을 단어)
- 내 강점 연결:
  - 요건 → 프로필의 근거 → 어필 문장 1줄
- 경험이 프로필에 안 보이는 주제 (2~3개): "경험 있으면 이렇게 / 없으면 이렇게" 한 줄씩
```

## 규칙

- 단념·약점 표현 금지. 차이는 인접 경험·빠른 학습으로 푼다.
- 마감일·급여·근무지·고용형태는 원문 문구를 그대로 옮긴다. 바꿔 말하거나 계산하지 않는다(예: "회사 내규에 따름"을 "협의 가능"으로 바꾸지 않는다).
- 분석도 길면 04의 "결과물 주기" 순서(구글 문서 → 파일 → 본문)로 준다.
- 끝에 한 줄: "이 내용으로 자소서 초안 써 드릴까요?"
